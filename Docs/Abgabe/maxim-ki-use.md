# Erklärung zur KI-Nutzung

## Angaben zum Projekt

Diese Erklärung legt offen, welche KI-Werkzeuge ich im Projekt **Impfany** eingesetzt habe, wofür ich sie genutzt habe und in welchem Umfang.

## Verwendetes KI-Werkzeug

Ich habe ausschließlich **Claude Opus 5.5** von Anthropic genutzt. Weitere KI-Werkzeuge, zum Beispiel zur Code-Vervollständigung in der Entwicklungsumgebung, habe ich nicht verwendet.

## Wofür ich KI genutzt habe

Ich habe Claude vor allem wie ein Nachschlagewerk genutzt und als Hilfe, wenn ich bei einem Problem nicht mehr weiterkam.

### Syntax und Konzepte erklären lassen

Wenn ich nicht wusste, wie etwas in C# oder Unity geschrieben wird, habe ich es mir erklären lassen. Ein Beispiel ist der Aufbau eines switch-case. Außerdem habe ich mir Unity-Funktionen erklären lassen, zum Beispiel Events, Kollisionen und das Erzeugen von Objekten zur Laufzeit. Das meiste habe ich mir durch YouTube-Tutorials beigebracht.

### Fehlermeldungen verstehen

Wenn ich bei einer Fehlermeldung nicht mehr weiterwusste, habe ich sie mir erklären lassen. Das betraf vor allem typische Unity-Fehler wie eine NullReferenceException. Die Ursache habe ich danach selbst im Code behoben und das Ergebnis im Spiel getestet.

### Einen Merge-Konflikt lösen

Einmal habe ich einen Merge-Konflikt in Git mithilfe von KI gelöst. Das Ergebnis habe ich anschließend geprüft, bevor ich es übernommen habe.

## Eigene Leistung

Den Code habe ich selbst geschrieben. Wenn mir die KI eine Korrektur oder ein kurzes Beispiel gezeigt hat, habe ich es zuerst nachvollzogen und dann selbst in meinen Code eingebaut. Ich habe nur übernommen, was ich verstanden habe und erklären kann.

## Erklärung

Hiermit versichere ich, dass ich die Nutzung von KI-Werkzeugen in diesem Projekt vollständig und wahrheitsgemäß angegeben habe. Alle nicht angegebenen Teile sind meine eigene Leistung oder mit Quellenangabe gekennzeichnet. Mir ist bekannt, dass falsche Angaben prüfungsrechtliche Folgen haben können.
