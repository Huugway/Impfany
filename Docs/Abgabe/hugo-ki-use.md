# AI Declaration – Hugo (Impfany)

I used Opus5.5 and Fable 5.2 on the Claude Desktop app. I gave the AI access to the Repository on my disc, to read Architecture, Scripts and Settings. The AI wasn't allowed to write in Unity with the exception of merge conflicts and import scripts.

I asked AI to Troubleshoot and review my code. I occasionally asked for certain industry standard procedures and pre-made functions or Unity tools. If a problem occurred, that i wasn't able to solve, i explained my problem and ideas to the AI to learn how i can fix the problem. Every decision was made by me instead of the AI and all of the code is hand typed with a few listed exceptions ("Player Animator" and "Player Coin Heal").

I used AI as and guide, troubleshooter and search engine and intentionally refused CLI access.
