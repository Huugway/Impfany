## Aufgaben (Folientext)

1. Think about the user interface of your game
   1. Discuss the interaction model of your game and describe your feedback loop
      - [ ] Examine both gulfs of evaluation and execution (Norman)
      - [ ] Check Shneiderman's 8 Golden Rules on your game and find optimizations
   2. Check the graphical and audio user interface of your game
      - [ ] Where should you display data and information in your game
      - [ ] Where do you want to make use of Gestalt laws and where can you improve?
      - [ ] Research existing game GUIs and how they display such data, are there style guides?
   3. Elaborate on different perspectives of the development team and the player
      - [ ] What part of the system model needs to be part of the conceptual model and how?
      - [ ] How does your presented model help a user create a mental model that matches the conceptual model?
2. - [ ] Improve your game prototype accordingly (Vorher/Nachher dokumentieren: Screenshot oder Clip)

## Shneiderman-Checkliste (je ein Impfany-Beispiel)
- [ ] 1 Strive for consistency
- [ ] 2 Enable frequent users to use shortcuts
- [ ] 3 Offer informative feedback
- [ ] 4 Design dialogs to yield closure
- [ ] 5 Offer simple error handling / prevent errors
- [ ] 6 Permit easy reversal of actions
- [ ] 7 Support internal locus of control
- [ ] 8 Reduce short-term memory load
